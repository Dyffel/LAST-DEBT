LAST DEBT — v1.0 Gameplay Preview

Open lastdebt-v1.0-gameplay.html in a browser (or upload this ZIP's files to your GitHub Pages repository root, then visit /lastdebt-v1.0-gameplay.html).

This is a standalone LOCAL prototype. It does NOT modify the Create/Join lobby or connect to Supabase. To wire the host START GAME button to this screen after all 3 are ready, we first need real synchronized lobby state and a host-only start action.

Current test controls: Draw once, choose card, choose target/bet, Play. Turns cycle among Tommi, Noel, Aaron on one device. Shield is discarded on own turn; reaction/block and bluff/challenge rules are NOT implemented yet. The BELIEVE/CHALLENGE buttons are deliberately disabled. This is a UI/gameplay test, not final balanced gameplay.
